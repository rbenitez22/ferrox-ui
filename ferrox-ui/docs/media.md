# media (feature `media`)

Things shown a page at a time.

A carousel pages through items the user swipes or steps through. It holds
any item (a tile, a card, an image) laid out by the app, one page at a
time. Autoplay, images with captions and a lightbox are not here.

Which to use: [choosing.md](choosing.md#media).
